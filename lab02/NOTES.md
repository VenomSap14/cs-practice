Рабочая папка - это место где вы в настоящий момент создаёте и редактируете файлы
Индекс - это коробка в которую мы склавываем файлы которые хотим включить в следующий снимок
Коммит - это сохраненный снимок состояния файлов из индекса

Git - это инструмент для создания версий программ
GitHub - это сайт на котором хранятся версии программ в облаке

Использованные комманды:
git status - показывает общее состояние репозитория
git diff - показывает изменения в папке которые еще не добавили в индекс
git diff --staget - показывает изменения которые уже добавили в Индекс но еще не закоммитили

Ветка — это легкий подвижный указатель на конкретный коммит в истории разработки, который позволяет изолированно работать над кодом, не меняя основной проект.
Новый коммит — создает свежий снимок файлов, связывает его с предыдущим, а указатель текущей ветки автоматически сдвигается вперед на этот созданный коммит.
Слияние — это объединение изменений из одной ветки в другую. Git берет код из целевой ветки, добавляет в текущую и (при необходимости) создает специальный коммит слияния.
